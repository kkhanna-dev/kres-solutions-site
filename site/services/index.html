Services

Everything we do, in plain terms. Every job is scoped and priced before we start.

Secure your logins

Works with Microsoft Entra ID, Okta, and Google Workspace

Make sure only the right people can get into your company's accounts, and only as far as they need.

  • Two-step login (MFA) for everyone
  • Single sign-on, so staff use one secure login for all their apps
  • Rules that block risky sign-ins, like logins from unknown devices (Conditional Access)
  • Cleanup of admin accounts and who has admin rights
  • Access removed the day someone leaves
  • Secure login for your own app's customers

Security check

Usually 2 to 3 weeks

We review how your company is set up, fix the biggest problems, and give you a short report you can show customers.

  • Review of your Microsoft 365 and Azure settings
  • Review of AWS or Google Cloud, if you use them
  • Review of accounts and admin access
  • Fixes for the highest-risk problems
  • A plain-English report of what we found and fixed

We check against published standards from Microsoft and the Center for Internet Security (CIS).

Protect the software you build

For companies that write their own code

Security built into how your software is written and released, so problems are caught before customers see them.

  • Passwords and keys kept out of your code
  • Automatic checks for unsafe code libraries
  • Secure build and release pipelines (GitHub Actions, Azure DevOps)
  • Logs of who accessed sensitive data
  • Review of your login and permission code

Customer security questions and audits

One-time or ongoing

Bigger customers often ask for proof that you're secure before they sign. We help with that paperwork.

  • Filling out security questionnaires
  • Writing your security policies
  • Getting ready for SOC 2 or ISO 27001 audits
  • A security page for your website

We get you ready for audits. The audits themselves are done by independent firms.

Common questions

We're a small business. Do we need this?

Small businesses are targeted all the time, mostly through stolen passwords. The basics are quick to fix and cost far less than dealing with a breach.

What do you need from us to start?

A 30-minute call. After that, temporary access to your admin accounts, which we set up with you and remove when we're done.

Which systems do you work with?

Mostly Microsoft 365 and Azure. We also work with Google Workspace, AWS, Google Cloud, and Okta.

How much does it cost?

It depends on the size of your company. After the free call we send a fixed price, so you know the cost before you commit.
